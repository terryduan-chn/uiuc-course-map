快速上手

UIUC Course Map 列出 UIUC 的每一门课，包括官方介绍、先修课、平均 GPA 和开课学期，还能帮你一学期一学期地规划剩下的学位。 所有课程都来自官方 Course Explorer 数据，没有一门是手动录入的。

你可以按任意顺序这样用它：

  • 查资料：找到一门课，看它需要什么、又能通向什么。
  • 标记课程：记下你修过的、正在修的和打算修的课。
  • 规划学位：上传学位 audit，让自动规划排好各个学期，再自己调整。

不需要注册账号。你标记的所有内容都只保存在这个浏览器里（详见你的数据）。

查找课程

  1. 点顶栏的课程，在搜索框里输入。课程代码有没有空格都行（CS 225、cs225），也可以输入课程名里的词（linear algebra）。
  2. 也可以直接浏览：在首页选一个学科（学科上方的框可以筛选，比如 comp sci），再用跳到前往某个课程编号或级别（100、200……）。
  3. 卡片 / 列表可以切换课程的排列方式。

每张课程卡片上都有+ 计划，点一下就能加入下学期。已经标记过的课会改为显示状态：✓ 已修、在修、✓ 已有学分，或者计划的学期。

查找通识课

  1. 打开搜索框下方的通识要求菜单，选一项或多项要求。
  2. 列表会显示同时满足这些要求的课程，平均 GPA 高的排在前面。选两项（比如 Humanities 和 Western Cultures）就能找到一门课同时算两项的课程。
  3. 也可以再在搜索框里输入，进一步缩小范围。

在课程页上，每个通识标签都是一个按钮，点一下就能看到满足同一项通识要求的所有课程。

课程页

打开任意一门课，可以看到：

  • 平均 GPA、拿到 4.0 的学生比例，以及下次或最近一次开课的时间。
  • 先修课，按要求分组：每一项要么是必修，要么是 n 选 k，每门课都能点开。下面附有 UIUC 的官方原文。
  • 课程介绍、选课信息（限制、费用）和开过课的学期。
  • 在星图中打开，看这门课需要什么、解锁什么。

标题下方的框用来标记课程：+ 加入计划（已帮你选好最合适的学期）、我修过了或我正在修。详见标记课程。

星图

星图把每门有先修关系的课显示成一颗行星。行星越大，需要它的课越多；颜色代表学科。

  1. 拖动可以旋转，滚轮可以缩放，点击行星可以打开它。
  2. 也可以在星图的搜索框里输入：课程代码（CS 225）、学科（MATH）、编号开头（CS 4）或课程名里的词。学科菜单可以把星图缩小到几个学科。
  3. 打开一门课后，金色连线是它需要的课，蓝色连线是它解锁的课。← 返回星图回到完整星图。
  4. 2D 用分栏显示同一门课：往前两步、这门课、往后两步。
  5. 我的课程会给你已修、已计划和接下来可以修的行星上色。

专业

专业页列出所有本科专业和方向，还能根据目录规划整个学位。它不需要 audit，所以如果你还在选专业，或者还没上传 audit，可以从这里开始。

  1. 按名称搜索，或从列表里打开一个专业。搜索方向也能找到它所属的专业。列表可以按学院或按 A–Z 排列，也可以显示成卡片或列表，用上方的跳转栏可以跳到某个学院或字母。
  2. 每个专业页都按目录原本的顺序和措辞显示要求。已修的行是绿色，已计划的行是蓝色，现在可修表示你已满足这门课的先修要求。
  3. 点一门课上的+ 计划，就能把它放进“我的计划”的下学期。
  4. 如果专业下面有方向，先打开一个方向，因为每个方向的要求都不一样。Computer Science 没有方向，而是有重点方向：选一个就能看到它的课程，规划时也会用它。
  5. 规划我的学位会把它设为你的专业，并从下学期一直排到毕业：必修课、列表里选出的课，以及通识和选修空位。你自己计划的课保持不变，撤销可以恢复原来的计划。设为我的专业只是记下你的选择，之后可以在“我的计划”里规划。
  6. 只加必修课只加入必修课和它们需要的先修课，其余的留给你。

计划会尽量读懂目录里的列表，读不懂的也会告诉你：有些页面的选项是嵌套的，比如主攻领域下面还有各自的列表。计划排到学位所需的学分就会停下，并告诉你哪些部分要到官方页面自己选。它默认你可以直接修微积分，并且已经满足外语要求。

这不是官方结果：这里只是目录原文加上你的课程标记，不算学位审核。根据目录排出的计划只是一个起点。最终以你的学位 audit 和 advisor 为准。

标记课程

一门课可以有四种标记：

已修
你已经修完了。在课程页点我修过了。
在修
你这学期正在修。在课程页点我正在修，或在“我的计划”里点添加为在修。计算先修要求时，它算作已修。
入学前学分
AP、水平考试或转学分。这些来自你的学位 audit。
已计划
你打算在某个学期修。在课程页点+ 加入计划，或在课程卡片上点+ 计划。

要取消标记，再点一次亮着的已修或已计划按钮，或者点“我的计划”里课程卡片角上的 ✕（也可以在 ⋯ 菜单里选从计划中移除）。上传学位 audit 可以一次标记所有修过的和正在修的课。

我的计划

我的计划按学期排列你的课程：从本学期起四年的秋季和春季，课程排得更远时会自动延长。

  • 进度条：显示已获得、已计划和待规划的学分，总数是你的学位需要的学分（来自 audit；没有 audit 时按 120 学分算）。
  • 本学期显示你正在修的课，标记为在修。入学前学分有自己的卡片，不算在任何学期里。
  • 移动课程：把卡片拖到另一个学期，或用 ← 和 →。
  • 查看改动的影响：移动或移除一门课后，会有提示告诉你哪些课要推迟或不能再修，以及修完时间有没有变。受影响的课会加上边框，其他课不会自己移动，撤销可以恢复计划。
  • 点击卡片可以看 GPA、开课季节、先修课和它解锁的课。
  • 课程下方的通识标签说明它计入哪些通识要求。一门课可以同时计入两项，比如 Humanities 和 Western Cultures。
  • ⋯ 可以选学期、标记为已修或在修、换成满足同一要求的另一门课，或者移除这门课。
  • 红色标记指出问题：先修课没有排在更早的学期、这个学期不开这门课，或者这门课最近没开过。如果 UIUC 允许某门先修课“credit or concurrent registration”，它可以排在同一学期。
  • 学期不足 12 学分时显示偏少，超过 18 学分时显示偏重。

添加课程可以按代码添加，状态可选已计划（放在你选的学期）、在修或已修。底部的接下来可以修列出先修要求已被你的计划覆盖的课程。

自动规划

没有 audit 时，选好专业，自动规划就会改为根据目录规划学位。 上传学位 audit 后，“我的计划”里的自动规划我的学位会从下学期起，为你还需要的每项要求排课，每学期约 15 学分。

  • 你自己计划的课不会变，自动规划会绕开它们来排。
  • 它加入的课会标上自动，并注明用于哪项要求。
  • 通识要求会变成通识空位，由你来填。
  • 像“CS 397 or any 400-level course”这样的要求，会排上该学科的真实课程（CS 400 和 500 级的课，本科课优先）。
  • 学位要求之外还差的学分（多数学位总共 128 学分）会变成选修空位：每个 3 学分，任选一门课填上。
  • 运行后如果还有填不上的要求，提示里会列出来。
  • 重新规划会再运行一次；清除自动生成的会移除它加入的所有内容。

规则详见自动规划怎么选课。

通识空位

通识空位是一张虚线卡片，先为某项通识要求（比如人文与艺术）占个位置，等你之后再选课。它算 3 学分，可以像课程一样移动。

有些课能同时计入两项通识：比如一门 Humanities 或 Social Science 课同时也是 Western、Non-Western 或 U.S. Minority Cultures 课。这时自动规划只会建一个共用空位（比如人文与艺术 + 西方/比较文化），而不是两个，能省下 3 学分。它的课程列表会把两项都计入的课排在前面；如果你选了只计入一项的课，另一项会留下来成为单独的空位。

  1. 点空位上的选课。课程按这个顺序排列：先是那个学期能修的，再是还能填另一个空位的，然后是 GPA 更高的。
  2. 选一门课，它就会取代空位。如果它还计入另一个空位（比如 Humanities 和 Western Cultures），那个空位也会一起填上。
  3. 也可以在通识课的课程页上点用来填我的……空位，直接把它放进空位。

你也可以自己添加空位：在添加课程下面找到或者先给通识课留个位置。为空位选的课，⋯ 菜单里有退回为空位；换课时，新课覆盖不到的空位会重新打开。

学位审核

  1. 在 uAchieve 里运行 audit，打开 Audit Results 标签页。
  2. 打印这个页面，选择另存为 PDF。
  3. 在学位审核页选择这个 PDF，或把它拖到框里。

之后学位审核页会显示：

  • 顶部的还剩什么：每项未完成的要求占一行，写明它需要什么，以及你的计划是否已覆盖（已在计划中、部分已计划或尚未计划）。点一行可以跳到对应位置。
  • 每项未完成的要求和能计入它的课程，最合适的在前，并用颜色区分已计划、现在可修和需要先修课。修过的课只列一次，算作已计入；最近没开的课不会列出。
  • 对“几选一”的要求（比如 CS 的 focus area），显示每个选项你的计划能做到哪一步。最接近的会标出来并展开。
  • 对通识要求，显示你的计划里已有什么：能计入的已计划课程和空位。
  • 已完成的要求和部分，折叠在页面底部。
  • audit 上的 GPA（总、UIUC、技术课程和学院），每项都带学分数。“我的计划”里也会显示。
  • 用这份 audit 做计划，也就是运行自动规划。

上传后还会标记你的课程：修完的算已修，本学期的算在修，AP、水平考试或转学分算入学前学分，每门课都用 audit 记的学分。

你的计划跟着 audit 走。上传更新的 audit 会用它重新开始计划；全部清除（学位审核页和“我的计划”里都有）会在询问后，把 audit 和整份计划从这个浏览器删除。

PDF 只在你的浏览器里读取，不会上传到任何地方。这里只保存要求、课程代码和 GPA，绝不保存你的姓名或学号。这份清单是非官方的，最终以 advisor 和官方 audit 为准。

数据来源

  • 课程来自 UIUC 官方 Course Explorer 数据：课程名、介绍、学分、先修课、通识要求和选课信息，范围从最早到最新的目录。一门课出现在多个目录里时，用最新的条目；不在最新目录里的课，课程页上会注明。
  • 专业和方向来自官方 Academic Catalog，由导入脚本读取。
  • 开课时间来自最早学期以来的课表。“仅秋季”或“仅春季”表示这些学期里它只在那个季节开过。
  • 平均 GPA 和拿到 4.0 的比例（A 和 A+）来自 Wade Fagen-Ulmschneider 的 GPA 数据集，按学生人数加权。统计范围是最早学期到最新学期，和他的 GPA 可视化用的是同样的近几年，所以数字一致。这几年没开过的课没有成绩数据，20 人及以下的班级也没有，因为学校不公布。

数据最后导入于 导入日期。

先修课是怎么读取的

Course Explorer 用一句话写出每门课的先修要求。应用会把它拆成几项要求：每项是一组课程，你需要修其中若干门（必修表示就是这一门，3 选 1 表示任选一门）。“Recommended”的课不算在内，“consent of instructor”这类不是课程的条件也不算。

如果原文写着“credit or concurrent registration in”某门课，那门课可以同一学期修，不必提前修：比如 CS 222 可以和 CS 225 一起修。计划、问题标记和自动规划都允许这样，课程页上也会写“可以同时修”。

这种读取只能尽量准确，所以每个课程页都附有官方原文，一切以原文为准。计划的问题标记、星图和自动规划用的都是这些要求分组。

自动规划怎么选课

对你还需要的每项要求，自动规划都走最省事的路：

  1. 优先用计划里已有、能计入这项要求的课。
  2. 其次是需要额外先修课最少的课。
  3. 然后本科课优先于研究生课（500 级）。
  4. 最后选平均 GPA 最高的。

如果要求写着“从这些方向里选一个”，它会选需要新课最少的方向。它还会加入所选课程需要的先修课，并排除最早学期以来没开过的课。

然后它按顺序填学期。一门课会放进第一个满足条件的学期：先修课排在更早的学期（允许 concurrent registration 时也可以同一学期），而且这个季节开课。先修链最长的课先排，通识空位最后排。一个学期约 15 学分；只在一个季节开的课可以把学期撑到 18 学分，免得多等一年。

你的数据

  • 你标记的内容、计划、空位和 audit 里的要求，都保存在这台设备的这个浏览器里。没有账号，也没有服务器，你标记的内容不会发送到任何地方。
  • 换一个浏览器或设备，内容就是空的。想在那里使用，重新上传 audit 就行。
  • 全部清除会移除你的 audit 和计划；在浏览器里清除这个网站的数据，效果也一样。
  • audit 里只保存要求、课程代码和 GPA，绝不保存你的姓名或学号。

常见问题

本学期没有显示在修的课。

应用支持“在修”之前保存的课，看起来就是普通的已修课程。“我的计划”里会有提示：重新上传 audit，或点标记为在修。你也可以用添加为在修逐门添加。

我的计划不见了。

计划只保存在一台设备的一个浏览器里。请确认你用的是同一个浏览器，而且网站数据没有被清除。重新上传 audit 可以恢复课程，但已计划的课需要重新添加。

我知道的一门课不在应用里。

应用收录了最早目录以来 Course Explorer 目录里的每门课。请检查代码（搜索也接受 cs225 这样的写法）。如果这些目录里都没有，这门课应该在那之前就停开了。

一门课不在星图上。

只有需要别的课、或被别的课需要的课程才是行星。它的课程页上会说明。

“我的计划”的学分和目录对不上。

有 audit 时，已修课程用的是 audit 记的学分，可能和目录不同（有些水平考试学分算 0 学分）。

计划和官方 audit 不一致。

计划和自动规划都是非官方的，只能尽量准确。两者不一致时，以官方 audit 和你的 advisor 为准。

一门课被标记为“仅秋季”开课。

最早学期以来，它只在秋季开过。院系确实会调整课表，所以依赖这一点之前，请先到 Course Explorer 确认。
